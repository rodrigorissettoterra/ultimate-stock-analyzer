# Project Charter

**Project:** Ultimate Stock Analyzer

**Purpose:** build an open, reproducible and explainable Brazilian-equity research system that ranks regular dividend payers using comprehensive financial analysis while separating long-horizon quality from short-horizon entry timing.

**Primary user outcome:** reduce a large B3 universe to a defensible ordered research list with current/last price, dividend yield, securities-lending indicators, decomposed scores, red flags, confidence and evidence-backed explanations.

**Non-goals:** guaranteed return prediction, high-frequency trading, autonomous brokerage execution, secret/proprietary data redistribution, and LLM-generated authoritative financial numbers.

**Operating principles:** free-first, public-by-design, point-in-time correctness, sector awareness, deterministic scoring, evidence traceability, explicit uncertainty and backtest-before-trust.
